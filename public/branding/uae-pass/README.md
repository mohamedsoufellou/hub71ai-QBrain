# UAE PASS button assets

Official SVG button artwork downloaded on 2 October 2026 from [UAE PASS Button Assets](https://docs.uaepass.ae/guidelines/design-guidelines/button-guidelines/button-assets). The documentation links the `UAE PASS Buttons.zip` archive hosted by its GitBook file service.

Selected archive paths: `UAE PASS Buttons/svg/{EN,AR}/{Sign in with,Sign up with}/Pill/Active.svg`.

Files are copied without artwork changes. Preserve each SVG's aspect ratio, colours, and wording when displaying it. English sign-in is 264 × 50, Arabic sign-in 304 × 50, English sign-up 270 × 50, and Arabic sign-up 284 × 50.

These assets appear in Wusool's clearly labelled local authentication demonstration. That demonstration does not connect to UAE PASS or establish a verified identity.

Reference: [UAE PASS Button Guidelines](https://docs.uaepass.ae/guidelines/design-guidelines/uaepass-button-guideline).
